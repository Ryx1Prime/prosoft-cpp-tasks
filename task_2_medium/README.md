# 3. Longest Substring Without Repeating Characters (Medium)

Ссылка на задачу: https://leetcode.com/problems/longest-substring-without-repeating-characters/

# Условие:
Дана строка s. Нужно найти длину самой длинной непрерывной подстроки без повторяющихся символов.

# Идея решения:
Метод скользящего окна (два указателя left и right):
- Идём правым указателем right по строке и запоминаем последний встреченный индекс каждого символа в хэш-таблице.
- Если символ уже встречался внутри текущего окна (его сохраненный индекс >= left), сдвигаем левую границу сразу за этот символ: left = last_pos + 1.
- На каждом шаге обновляем позицию текущего символа и пересчитываем максимальную длину: max_len = max(max_len, right - left + 1).

# Сложность:
- По времени: O(n), указатель right проходит строку один раз, чтение и запись в таблицу работают за O(1).
- По памяти: O(min(n, m)), где m - это размер используемого алфавита уникальных символов.
