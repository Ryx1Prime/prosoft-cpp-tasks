# 20. Valid Parentheses (Easy)

Ссылка на задачу: https://leetcode.com/problems/valid-parentheses/

# Условие:
Дана строка из скобок ()[]{}. Нужно проверить, что все скобки закрываются в правильном порядке и парами одного типа.

# Идея решения:
Используем стек (LIFO):
- Если длина строки нечётная, сразу возвращаем false.
- Идём по строке: если скобка открывающая, кладём в стек.
- Если закрывающая, смотрим на верхушку стека: если стек пустой или скобка не совпадает с парой, возвращаем false. Если совпала, убираем её из стека через pop().
- В конце проверяем, что стек пустой.

# Сложность:
- По времени: O(n), один проход по строке длины n.
- По памяти: O(n), в худшем случае весь стек забьётся открывающими скобками.
