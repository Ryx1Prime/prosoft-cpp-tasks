# 42. Trapping Rain Water (Hard)

Ссылка на задачу: https://leetcode.com/problems/trapping-rain-water/

# Условие:

Дан массив неотрицательных целых чисел height, где каждый элемент задаёт высоту столбика шириной 1. Нужно посчитать, сколько единиц воды задержится между этими столбиками после дождя.

# Идея решения:

- Используем технику двух указателей: ставим left в начало массива, а right в конец.

- Также храним максимальные высоты стенок, встреченные слева (left_max) и справа (right_max).

- На каждом шаге смотрим, с какой стороны столбик ниже или равен: вода удерживается более низкой стенкой, поэтому расчёт ведётся относительно неё.

- Если текущий столбик ниже встреченного максимума своей стороны, то образуется яма, и разница высот добавляется к ответу. Если выше или равен, то обновляем текущий максимум.

- Сдвигаем соответствующий указатель навстречу другому (left++ или right--), пока они не встретятся.

# Сложность:

- По времени: O(n), где n это длина массива height. Каждый указатель проходит массив за один проход.

- По памяти: O(1), так как используются только несколько числовых переменных для хранения индексов и максимумов.
