# 347. Top K Frequent Elements (Medium)

Ссылка на задачу: https://leetcode.com/problems/top-k-frequent-elements/

# Условие:

Дан массив целых чисел nums и целое число k. Нужно вернуть k наиболее часто встречающихся элементов массива.

Порядок элементов в ответе не важен.

# Идея решения:

- Сначала проходим по всему массиву и с помощью хэш-таблицы считаем, сколько раз встречается каждый элемент.

- Затем переносим элементы вместе с их количеством в отдельный массив, чтобы можно было их отсортировать.

- Сортируем элементы по количеству повторений от большего к меньшему.

- После сортировки берём первые k элементов, так как именно они встречаются чаще всего, и добавляем их в ответ.

# Сложность:

- По времени: O(n log n), где n это количество элементов в массиве. Подсчёт частот занимает O(n), а сортировка в худшем случае занимает O(n log n).

- По памяти: O(n), так как в худшем случае все элементы массива могут быть уникальными.
