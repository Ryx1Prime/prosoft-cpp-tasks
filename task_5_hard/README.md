# 23. Merge k Sorted Lists (Hard)

Ссылка на задачу: https://leetcode.com/problems/merge-k-sorted-lists/

# Условие:

Дан массив из k односвязных списков, каждый из которых отсортирован по возрастанию. Нужно объединить все списки в один отсортированный связный список и вернуть его.

# Идея решения:

- Для быстрого поиска минимального узла среди всех списков используем очередь с приоритетом (min-кучу) на основе кастомного компаратора.

- Сначала добавляем в кучу головы всех непустых входных списков (в куче лежит не более k элементов).

- Создаем фиктивную начальную вершину (fictional node), чтобы удобно собирать результирующий список без лишних проверок на null.

- В цикле извлекаем минимальный узел из кучи, прикрепляем его к хвосту результирующего списка и продвигаем хвост.

- Если у извлечённого узла есть следующий элемент в его исходном списке, добавляем этот следующий узел в кучу. Повторяем процесс, пока куча не опустеет.

# Сложность:

- По времени: O(N log k), где N - общее количество всех элементов во всех списках, а k - количество списков. Каждое добавление и извлечение из кучи размера k занимает O(log k).

- По памяти: O(k), так как в куче одновременно находится максимум по одному узлу от каждого непустого списка.
